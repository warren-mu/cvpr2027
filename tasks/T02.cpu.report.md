# T02 CPU 子步骤报告（非最终验收报告）

本次只完成统一环境接口、合成后端和 VAGEN 接口骨架的 CPU 验证。24 项测试通过；没有选择或实现真实 L/P 后端，也没有完成 T02 的真实见证回放、吞吐量或后端一致性验收。T02 仍未完成。

## 实现范围

- [paired_env.py](../src/envs/paired_env.py) 提供 `reset(pair_id, world)` 和 `step(action)`。模型只得到实际带标号 RGB、完整公开文字及标号几何；目标、世界身份、类别标签、距离和证据证明保留在 privileged `info`，不进入策略输入。
- 一次观察动作只执行一个移动、45° 转向或打开操作，然后返回新捕获；`select` 终止回合。成功要求稳定物体名匹配目标、当前实例掩码非空、类别合法且实测距离 ≤1.5m。公开可选动作只取决于公开候选角色与可见标号，不泄漏私有距离或成功类别；可见候选选得太远或不符合成功条件得到 0。
- 前缀比较包含实际 RGB、公开文字和标号；原始 RGB 另作严格审计。证据要求独立来源捕获、相关掩码并集内通道差 >10、按面积缩放的 250/255² 像素阈值，而且差异在实际带标号输入中仍可见。缺少比较保持 `unknown`；渲染噪声不自动成为证据。证据一旦进入历史，之后不因缺失新比较而撤销。
- [paired_mock.py](../src/envs/paired_mock.py) 仅接受显式合成帧；不能认证真实前缀或来源。[paired_vagen.py](../src/envs/paired_vagen.py) 提供 pinned legacy BaseEnv 形状的接口骨架，注入选择器、图像转换、解析器和真实 tokenizer；没有服务注册、序列化或训练器接入。
- [接口草稿配置](../configs/t02_interface_draft.json) 明确标记未冻结：8 轮、8 次逻辑模型调用、256 token 来自 T04 草稿；无效动作奖励仍为 `null`，调用者必须显式提供。没有创建或冻结公共训练配置。
