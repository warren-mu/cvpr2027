## 1. 记号
- p(w)：世界的先验权重，p(w1) = r_train，p(w0) = 1 − r_train。主实验 r_train = 0.5。
- **τ** 与 **τ_seen**：由 T02 查表环境给出（`info.tau`、`info.x_seen_step`），定义见 METRICS_SPEC §1b。
  - τ = 第一次到达分叉状态的步号。t < τ 的步叫**证据前的步**：两个世界的全部输入逐字节相同。
  - 所有臂（包括只用单个世界训练的 T0、T2）都用同一个定义，状态表是预先算好的。直接类世界对 τ = 0，没有证据前的步。
- G(w, t)：世界 w 中从第 t 步起实际得到的回报，包括之后每个观察动作的 −λ 和最终 `select` 的奖励。
- Q_commit(w, t)：如果在第 t 步立即 `select`，在世界 w 里的期望奖励，即 Σ_c π(select c | h_t)·1[c 是 w 的正确目标]。
  - 候选上的概率，通过对每个候选的 `select <标号>` 动作文本打分得到，**不需要额外跑回合**。
  - 在所有可选候选上归一化，只计 `select` 动作的概率质量，不含观察动作。
- GAE(w, t)：世界 w 的轨迹在第 t 步的标准 GAE（价值网络基线）。
- **没有可选标号的证据前步**（当前画面里没有任何候选带标号，不能立即 `select`）：「立即承诺」这个对照不存在，Q_commit 无定义。这些步上：
  - T2 用 GAE(w, t)；
  - T3、T4 两个世界都用同一个值 Σ_w p(w)·GAE(w, t)。
  - 原规格写的是 Q_commit = 0。那等于这一步不用任何基线，方差大，已改掉。
- **证据前「无法解析的输出」那一步**（T02 §4：算一轮、不改变状态）：同样按上面「没有可选标号的步」处理。

## 1b. 实现细节（2026-11-09 02:10 冻结，回答 Codex 提出的三个问题；所有臂用同一套流水线）
1. **优势落到 token 上的方式**
   - 「步」指一轮（turn）：一次提示加一段回复。
   - **用 Q_commit 的证据前步**（T2、T3、T4）：这一轮的决策级优势（例如 T3 的 Σ_w p(w)[G(w,t) − Q_commit(w,t)]）赋给这一轮回复的**每一个 token**，取同一个值。
   - **回退到价值网络基线的证据前步**（没有可选标号，或者输出无法解析）：不做决策级聚合，直接用流水线原有的 **token 级 GAE**。
     - T2：用本世界的 token 级 GAE；
     - T3、T4：对两条轨迹中同一位置的 token，取 Σ_w p(w)·GAE_token(w, t, k)。共享前缀里两份副本的提示和回复逐字相同，token 一一对应，所以这个平均有定义，两份副本的结果也完全相同。
   - **证据后的步，以及 T0、T1 的所有步**：原有 token 级 GAE，不改。
2. **G 和 KL**
   - G(w, t) 和 Q_commit 都只算任务奖励：选对 +1、选错 0、每个观察动作 −λ，γ = 1。不含 KL。
   - **KL 统一做成 actor 的损失项**，不放进奖励（verl：`use_kl_loss = true`，`kl_loss_type = low_var_kl`，系数取 VAGEN 默认的 KL 系数；`algorithm.use_kl_in_reward = false`）。所有臂都一样，包括 T0。这样替换优势不会动到 KL，KL 对所有臂的作用也完全相同。这条写进 `configs/rl_common.yaml`，随 T04 一起冻结。T0 的 E2E 如果用的是别的设置，按这条重跑 5 步。
3. **替换与归一化的顺序**（所有臂相同）
   - ① 用 rl_common 的 γ、λ_GAE，算出**未归一化**的 token 级 GAE。verl 的 `compute_gae_advantage_return` 内部会做 `masked_whiten`，要拿到归一化之前的值。
   - ② 按上面第 1 条，替换证据前步的优势。
   - ③ 对整批的全部有效回复 token，统一做**一次** masked whiten（同一个均值和标准差）。归一化是同一个仿射变换，所以配对证据前两份副本的值在归一化后仍然相同；证据后仍是原 GAE（只经过同一次整体缩放）。
   - ④ PPO 损失中，配对臂按 §2 的世界权重 2p(w) 加权。
   - ⑤ critic 照常用原来的回报目标（GAE + V）训练，不用替换后的优势。
   - **单元测试**：
     - 不做替换时，① 到 ③ 的输出必须和 verl 原来的输出逐元素一致（回归测试）；
     - 替换后，配对证据前两份副本的 token 优势逐元素相同；
     - 证据后 token 的优势，等于「原 GAE 经过同一次整体归一化」。

## 2. 配对回合（T1、T3、T4 共用）
- 每次从训练池取一个世界对 (w0, w1)，两个世界各开一个回合，同步推进。
- **同步的实现：按提示内容去重。** 每一轮生成之前，在同一个世界对的两个回合之间比较完整提示（全部图像字节和全部文本 token，包括历史）：
  - 完全相同，就只生成一次，把同一个回复同时用于两个回合；
  - 不同，就各自生成。
  - τ 之前两个回合的提示必然相同（T02 保证共享状态下图像和文本逐字节相同），所以自动共用同一个动作；τ 之后提示不同，自动分开。不需要改 VAGEN「一个环境一条轨迹」的结构。
  - 等价的简单做法也可以：两个回合照常各自生成，但只要这一轮两边提示完全相同，就用 w0 的回复覆盖 w1 的回复。
- 两条轨迹都完整保留、都参与训练。共享前缀在两条轨迹里各出现一次，两份的 log-prob 相同。
- **世界权重**：配对臂里，世界 w 那条轨迹的每个 token 的损失乘以 2p(w)。r_train = 0.5 时权重都是 1，没有变化；训练变化频率 ρ ≠ 0.5（校准实验）时，靠这个权重让配对数据代表按 ρ 采样的世界分布。
- **预算对齐**：T0 和 T2 每步 64 个单世界回合（世界按 r_train 采样）；配对的臂每步 32 对，共 64 个回合。报告里另外给出各臂每步实际生成的 token 数（配对臂因为去重会少一些）。

## 3. 各训练臂的优势怎么算（研究合同 §4 第 3 条：2×2 设计）
| 臂 | 采样 | 证据前的步 | 其余步 |
|---|---|---|---|
| T0（T04 已做） | 单世界 | GAE（价值网络基线） | GAE |
| T1 | 同步配对 | 每个世界各自 GAE | GAE |
| T2（SeekVLN / C2PO 式，我们的改编） | 单世界 | 观察动作：G(w, t) − Q_commit(w, t)；`select`：R(w) − Q_commit(w, t)；只用实际所在的世界 w | GAE |
| T3 信息集信用 | 同步配对 | 观察动作：Σ_w p(w)[G(w, t) − Q_commit(w, t)]；`select`：Σ_w p(w)[R(w) − Q_commit(w, t)]。两个世界在这一步得到**同一个**优势值 | GAE |
| T4 完整方法 | 同步配对 | 同 T3 | 同 T3，另加证据后一致性损失（§4） |

**怎么解读**：
- 同步配对下，证据前的同一步在两条轨迹里各出现一次，梯度相加。所以在一阶近似下：
  - T1 的两份合起来 ≈ Σ_w [G(w, t) − V(h_t)]；
  - T3 的两份合起来 = Σ_w [G(w, t) − Q_commit(w, t)]（r_train = 0.5 时）。
  - 在 γ = λ_GAE = 1 时，两者只差基线。T1 **不是**「去掉跨世界关系」的消融，原来的说法已撤回。
  - T04 若沿用 VAGEN 的 γ、λ_GAE 且不为 1，T1 的 GAE 还会用价值网络自举，和 T3 的蒙特卡洛回报不同。这时 2×2 的第二个因素要如实写成「价值网络 GAE（γ、λ_GAE 取 rl_common.yaml 中的值）对 蒙特卡洛回报减 Q_commit」。γ、λ_GAE 在 T04 报告里写明。
- 2×2 的对比：
  - T3 对 T2：同步配对（在信息集内分层采样两个世界）的作用；
  - T3 对 T1、T2 对 T0：Q_commit 基线的作用；
  - T4 对 T3：证据后一致性的作用。
- 必做：T0、T2、T3、T4；应做：T1（研究合同 §5）。
- critic 照常训练。证据前的步用上表的优势，其余步照常用 GAE。

## 4. 证据后一致性（只用于 T4）
作为辅助损失加到 PPO 损失上，权重 β = 0.1，**只在本世界已经看到锚点（t ≥ τ_seen）时的 `select` 步上施加**：
- **Flip 对**：在世界 w 的 `select` 步上，如果 w 已经看到锚点，施加 hinge 损失：`log π(本世界正确目标) − log π(另一个世界的正确目标) ≥ m`，m = 1.0。
- **Stay 对**：两个世界的 `select` 步都已经看到锚点时，对两个世界在候选上的选择分布施加对称 KL。候选按稳定的物体名对齐，不用 objectId。
- 为什么加这个条件：在 Look→Flip 的 w1 里，智能体可能只看到「A 旁边没有 X」就选择。这时它并没有看到 X，如果强迫它选 B，就是在教它根据「没看到」去推断。而 T01v2 补充 4 已经说明，这种推断在数据里并不总是对的。

m、β、λ、r_train 都写进 `configs/` 中各臂的配置，冻结后不再调整。

### 4b. 实现细节（2026-11-09 13:00 冻结，回答 Codex 的三个问题，在任何 T4 训练结果之前）
每个回合 i 最多有一个一致性项 c_i，挂在它最后那个合法的 `select` 步上；不适用时 c_i = 0。
1. **打分**：候选 c 的分数 s(c) 用与 Q_commit 同一个打分函数（完整动作文本的 token log-prob 之和）。
   - **Flip**：c_i = max(0, m − [s(本世界正确目标) − s(另一世界正确目标)])。两项都用本次更新中的当前 actor 计算，两项都传梯度。归一化常数在差值里抵消，不需要再归一化。
   - **Stay**：π_w 是本回合 `select` 步上 A、B 两个候选的分布（在这两个候选上归一化），用当前 actor 计算；π̂_other 是同一对另一个世界那个回合 `select` 步上的同样分布，用采样时的策略算出，视为常数、不传梯度。c_i = KL(π_w ‖ π̂_other)。
2. **问题①（对称 KL 取和还是取均值）**：每个世界的回合各带一个方向，所以一对 Stay 合计是 KL(π_0 ‖ π̂_1) + KL(π_1 ‖ π̂_0)，即**两项之和**。这和 Flip 一致：Flip 也是每个世界的回合各带自己的 hinge，一对合计两项。
3. **问题②（怎么归约到总损失）**：L_cons = (1/N) Σ_i 2p(w_i)·c_i。求和覆盖 PPO mini-batch 里的全部回合，N 是 mini-batch 的回合数，不适用的回合 c_i = 0 也计入 N。总损失 = PPO actor 损失 + KL 损失 + β·L_cons，β = 0.1。用 micro-batch 梯度累积时，每个 micro-batch 贡献 Σ_{i∈micro} 2p(w_i)·c_i / N。主实验 r_train = 0.5，2p(w) = 1。
4. **问题③（候选不可选，或两个世界的候选集合不同）**：
   - **Flip**：在本回合 `select` 步上，本世界正确目标或另一世界正确目标只要有一个没有标号（不可选），c_i = 0。理由：不可选的候选概率为 0，margin 要么已经无穷大，要么无法优化。
   - **Stay**：只有当 A、B 在两个世界的 `select` 步上都可选，并且两个回合都已在本世界看到锚点时，两个回合才各算一项；否则两个回合都是 c = 0。
   - 回合没有合法的 `select`（超出轮数，或最后一轮无法解析）：c = 0。对 Stay，它的配对回合也是 c = 0。
5. **记录**：每步记录适用的 Flip 项数、Stay 项数，以及按上面原因跳过的数目。
6. **留出评测的解码**：与 T03 相同，贪心解码；每对两个世界各 1 个回合；预算与训练相同（D + 1 轮，每轮最多 256 token）。

## 5. 单元测试（`tests/test_credit.py`，CPU 上用手工构造的小视角表和小回合）
- **提示去重**：τ 之前，同一世界对的两个回合每一轮只生成一次、动作相同；τ 之后各自生成。
- **相同输入，相同优势**：T3 和 T4 在每个证据前的步上，两个世界得到完全相同的优势值，包括没有可选标号的步。
- **T1 与 T3 只差基线**：在 γ = λ_GAE = 1 的手工例子上，证据前每一步两份副本的优势之和，T1 等于 Σ_w [G(w, t) − V(h_t)]，T3 等于 Σ_w [G(w, t) − Q_commit(w, t)]。
- **蒙对不被奖励**：构造一个 Look→Flip 对。立即 `select` 在 w0 里碰巧选对，在 w1 里选错；先看再选在两个世界都选对，但要扣 λ。
  - T3：观察动作的优势为正；
  - T2：在 w0 上奖励立即选，在 w1 上惩罚立即选。
- **不该看时不看**：构造一个 Look→Stay 对，立即选在两个世界都对。T3 中观察动作的优势应为负（观察要扣成本）。
- **一致性损失**：
  - Flip 的 hinge 和 Stay 的对称 KL，在手算的小例子上数值正确，候选按物体名对齐；
  - 本世界还没看到锚点的 `select` 步不施加。
- **Q_commit**：在手算的候选概率上数值正确。
- **世界权重**：r_train = 0.25 时，配对臂两条轨迹的损失权重分别是 1.5 和 0.5（w0、w1）。
- **预算对齐**：每个臂每步都是 64 个回合。
- **S1 记录**：每步按 METRICS_SPEC §3b 记录各独立决策单元的证据前信用之和（单世界臂按回合，配对臂按世界对、再除以 2），供 analyst 计算 S1。
