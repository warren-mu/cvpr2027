# 任务与审查流程（Codex 执行，Claude 审查）

| 文件 | 谁写 | 内容 |
|---|---|---|
| `tasks/<ID>.md` | Claude | 任务说明和验收标准 |
| `tasks/<ID>.report.md` | Codex | 做了什么、命令、结果路径、失败与异常、下一步算力预估 |
| `reviews/<ID>.md` | Claude | PASS / FAIL，以及具体的修改要求 |

一轮流程：
1. Claude 推送 `tasks/<ID>.md`。
2. 人类告诉 Codex：`git pull，按 AGENTS.md 执行 tasks/<ID>.md`。
3. Codex 实现、运行、审计（`scripts/audit_provenance.py`）、写报告、推送。
4. 人类告诉 Claude：`<ID> 推送了`。
5. Claude 拉取后审查代码改动、跑审计、核对日志和图，写 `reviews/<ID>.md` 并推送。
6. FAIL 就回到第 2 步；PASS 就进入下一个任务。
