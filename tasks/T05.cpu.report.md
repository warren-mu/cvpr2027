# T05 CPU 子步骤报告（非最终验收报告）

本次完成配对回合、信用分配数学、辅助损失与 S1/S2 原始记录接口的 CPU 验证。最初 17 项测试通过；加入 4 项 PyTorch 反向传播测试后，21 项全部通过。尚无真实后端、生产 scorer/GAE/PPO 集成或 T1–T4 GPU 冒烟，T04 公共配置未冻结，因此 T05 仍未完成。

## 实现与约束

- [credit.py](../src/rl/credit.py)：T0/T1 保留调用者提供的上游 GAE；所有臂证据后的步骤也保留 GAE。T2 证据前只用实际世界的 `G−Q_commit`（观察）或 `R−Q_commit`（选择）；T3/T4 按 `(1−rho, rho)` 加权，两世界获得同一个计算出的优势。缺失证据证明、未对齐的双世界步骤或不相同的共享输入明确拒绝，不伪造配对信用。独立 GAE 参考函数只用于 CPU 测试，不替代生产 `masked_gae`。
- `Q_commit` 保留模型完整动作事件的无条件概率质量，以 token log 概率求和，保留终止边界与打分来源；不在 select 候选内重新归一化，也不做长度归一化。候选按稳定物体名对齐，世界内动作文本使用当前公开标号。
- [paired_rollout.py](../src/rl/paired_rollout.py)：只有实际带标号 RGB、文字、标号、完整观测/响应/动作历史严格相等且来源符合约定时才共享一次采样。出现差异后单向分叉，不恢复共享；噪声分叉不等于证据进入。T0/T2 每批 64 个单世界回合，T1/T3/T4 每批 32 对、共 64 回合；物理采样次数与每世界逻辑调用分开记录。合成 fixture 不能认证真实共享前缀。
- T4 只在已分叉、已验证证据后的双方 `select` 上适用：Flip 使用 log 概率 hinge，margin=1；Stay 使用调用者显式提供、按稳定名字对齐的合法归一分布；权重 beta=0.1。Stay 不静默选择条件化策略、支持集交集或 epsilon，`sum`/`half_sum` 约定和训练归约方式仍待公共配置确认。

## S1/S2 从首次训练开始的记录接口

[credit_records.py](../src/rl/credit_records.py) 提供有大小上限、追加写入、哈希索引的原始 journal。每次更新前检查完整 64 回合及步骤覆盖，保留所有证据前步骤的 arm/seed/rho、pair/draw/episode/world/step、输入与采样身份、G/R/Q、GAE、逐世界未平均信用、权重、原始及实际应用优势、打分和证据来源。优化失败也保留更新尝试和完成状态；不自选经验方差 ddof 或分解方式。

S2 以真实完成的 PPO rollout-batch actor/critic 更新周期计数，每 20 次触发固定训练场景留出集请求；不以配置总步数或内部 AdamW minibatch 次数代替。留出 manifest 必须训练前固定，并排除优化对与冻结测试对/场景；逐回合记录成功或失败，不补初始/末尾点、不在接口内计算 AUC。这些 hook 只经合成 journal 测试验证，尚未接入训练，也没有 S1/S2 研究测量。
