# 指标规格 v3.2（预注册：G1 签字时冻结，之后修改需人类确认并记入 STATUS.md Decisions）

> v3.2 变化：动作空间改为离散视点；观察后端（实时 / 预渲染）由 D1 决定，所有实验统一；新增预渲染一致性检查。

> auditor 会请 Codex 按本文件独立重写关键指标并与我们的实现对比。

## 0. 通用约定
- 训练种子 3 个。评测集与**独立测试世界对**在 D1 生成后冻结（`experiments/eval_sets/*.json`），任何训练、搜索过程都看不到。
- 检查点：固定步数后的最后一个。动作取贪心解码。
- 每个种子先做 episode 平均，再对 3 个种子求均值 / 标准差 / 95% CI；"显著"= Welch 差值 95% CI 不含 0。
- **统一接口**：观察类动作（移动到相邻视点、左右转 45°、打开容器）执行后本轮结束，返回新帧再决策；`select` 是唯一的承诺动作；所有方法相同的每回合模型调用上限。

## 1. 世界对有效性（每对都记录）
| 检查 | 判定 | 字段 |
|---|---|---|
| 场景恢复确定性 | **2026-11-08 修订（人类确认）**：逐像素零差改为诊断记录（照常测量并保存 `restore_max_abs_diff`，不补写为零，不作为丢弃条件）。原因：T00b 诊断显示，reset 或跨进程后的渲染会带入与世界内容无关的低幅噪声，以及 agent 位姿的浮点漂移。替代的硬性门槛为状态级确定性：从保存的快照恢复后，所有可移动物体的位置与快照的偏差 ≤ 1 cm，agent 位姿与快照一致，且见证动作在两个世界都回放成功。智能体看到的前缀是否一致，由下面「信息一致」一行的前缀规则判定 | `restore_deterministic`（状态级）, `restore_max_abs_diff`（诊断） |

| 目标唯一 | 关系指令在两个世界中按当前状态各自解析出唯一目标 | `target_w0`, `target_w1` |
| 可执行 | 特权规划器在预算内完成，保存动作见证 | `witness_actions_w0/w1` |
| 信息一致 | t 时刻之前（含 t），智能体在两个世界中收到的输入逐像素一致（Look 类必须为真；直接 Flip/Stay 必须为假）。**实现方式（2026-11-08，T00b 诊断后）**：同一进程内、agent 不动，先渲染 w0 前缀，再用 SetObjectPoses 切到 w1 渲染前缀；只有当 (a) 两次独立渲染的整帧最大通道差 ≤ 3，且 (b) 被编辑物体（及其关系锚点）在前缀各帧中实例掩码像素为 0 时，才判为信息一致，此后训练和评测中两个世界共用同一组前缀帧（逐字节相同）。(a) 或 (b) 任一不满足即不是 Look 类 | `same_input_at_t`, `prefix_max_abs_diff`, `prefix_edit_mask_pixels` |

| 可解性（2026-11-08 提议，待人类确认；在任何训练或评测结果出现之前） | Look 类：在每个世界里，至少有一个一步观察动作（左右转 45°、移到相邻视点）执行后，该世界中锚点 X 的实例掩码 ≥ 250 像素（255×255 下），保证正确答案能靠观察得出。直接类已要求 X 在两个世界的 t=0 画面中可见 | `anchor_visible_actions_w0/w1` |
| 候选可区分 | 两个候选目标的成功判定互不重叠（以 `select` 动作判定） | `targets_separable` |

## 1b. 运行时「证据进入输入」的判定（2026-11-08 提议，待人类确认；在任何训练或评测结果出现之前）
- 每个回合同时运行两个世界，agent 位姿相同。被编辑物体（锚点 X）第一次在任一世界的画面中实例掩码 > 0 的那一步记为 τ。t < τ 的步属于共享前缀：智能体在两个世界收到同一帧（w0 渲染），逐字节相同。整帧像素差只作诊断。
- Premature-commit、证据后更新准确率，以及 T05 中各臂的「证据前的步」，都按这个 τ 计算。

## 2. 主要指标
- **SR**：`select` 选中正确目标，且执行 `select` 时所在视点到目标的距离 ≤ 1.5m、目标在当前画面中可见（以实例掩码像素判定）
- **Obs-cost**：每回合观察类动作数（移动、转向、打开容器各计 1）
- **成功率–观察成本曲线**：对每个方法，在不同观察代价 λ（或不同解码温度阈值）下得到的 (Obs-cost, SR) 点；报告曲线下面积与给定预算点的 SR
- **Premature-commit**：在 `same_input_at_t=True` 的世界对中，区分性证据进入输入前就执行 `select` 的比例
- **Post-evidence update accuracy**：证据进入输入后，正确改变（Look→Flip）与正确保持（Look→Stay）的比例，**两者分开报告**
- **Direct Flip / Direct Stay accuracy**：t 时刻证据已足够的世界对上的目标选择正确率
- **Calibration**（2026-11-08 修订，在任何训练结果出现之前）：用训练变化频率 ρ ∈ {0.25, 0.5, 0.75} 分别训练的模型，在同一冻结测试集上的平均观察次数，以及 Look 类世界对中「先观察再 select」的比例，应随 ρ 上升。测试变化频率三档 {0, 0.25, 0.5} 下的 SR 与 Premature-commit 作为稳健性结果报告。
  修订原因：Look 类世界对在证据进入输入之前两个世界的输入逐像素相同，智能体无法感知测试时的变化频率，原定义（测试频率越高观察越多）对固定策略不成立。

## 3. 主要终点（G1 时确定，不得事后更换）
- 在 50% 与 25% 变化频率的冻结测试世界对上：相同观察预算下的 SR 与 Premature-commit
- 约束：0% 变化频率（原任务）上 SR 不显著下降

### 3b. 次要终点（2026-11-08 预注册，在任何训练结果出现之前；不替代主要终点，论文必须同时如实报告主要终点）
- **S1 证据前信用的方差**：每个训练步，对 batch 中所有「证据前的步」（定义见 tasks/T05.md §1）的优势值求经验方差，在整个训练过程上取平均，按种子汇总（均值 / 标准差 / 95% CI）。主比较为 T3 对 T2（两者优势形式相同，只差是否在两个世界上取平均）；T4 一并报告。另外对 T3 的配对数据离线分解出「世界间」方差分量并报告。
- **S2 学习效率**：训练中每 20 步在训练场景留出子集上评测的成功率曲线，取曲线下面积再除以总步数，按种子汇总。比较 T4、T3 与 T0、T1、T2。留出子集在训练开始前固定，不使用冻结测试集。

## 4. 辅助指标（不作为"推理忠实"的证据）
- Change-ID：结构化状态描述中正确指出变化物体/关系的字段级 F1
- Template rate：不同状态下推理文本 8-gram Jaccard > 0.8 的比例
