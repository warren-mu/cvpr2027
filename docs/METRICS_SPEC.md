## 0. 通用约定
- 训练种子 3 个。评测集与**独立测试世界对**在 D1 生成后冻结（`experiments/eval_sets/*.json`），任何训练、搜索过程都看不到。
- 检查点：固定步数后的最后一个。动作取贪心解码。
- 每个种子先做 episode 平均，再对 3 个种子求均值 / 标准差 / 95% CI；"显著"= Welch 差值 95% CI 不含 0。
- **统一接口**：观察类动作（移动到相邻视点、左右转 45°、打开容器）执行后本轮结束，返回新帧再决策；`select` 是唯一的承诺动作；所有方法相同的每回合模型调用上限。当前任务族里没有容器，不提供「打开容器」。每回合最多 D 个观察动作、D + 1 轮（D 由 T02 定，在 T03 评测集冻结之前冻结）。

## 1b. 两个时刻：τ（证据进入输入）与 τ_seen（本世界看到锚点）（P 后端；2026-11-08 人类确认，在任何训练或评测结果出现之前）
- **状态分类**：T02 导出时，对起点附近视角表中的每个状态，在同一进程、agent 不动的条件下渲染两个世界。锚点 X 在两个世界的掩码都为 0、且两帧最大通道差 ≤ 3 的状态为**共享状态**：两个世界使用同一张画面（w0 渲染）和同一段文本，逐字节相同。X 在至少一个世界掩码 > 0，或两帧最大通道差 > 3 的状态，都是**分叉状态**（后者见 §1「无锚点泄露」，2026-11-09 修订）。
- **τ** = 回合中第一次到达分叉状态的步号。t < τ 的步，两个世界的全部输入逐字节相同，属于同一个信息集。T05 中各臂的「证据前的步」按 τ 计算。
- **τ_seen(w)** = 回合中第一次到达「在本世界 w 中 X 掩码 ≥ 250 像素」的状态的步号（日志与 info 字段名 `x_seen_step`）。智能体在这一步已经看到该画面，所以步号 ≥ τ_seen 的决策都算「看到之后」。直接类 τ_seen = 0。
- 为什么要两个时刻：τ 是「两个世界的输入开始不同」，决定信用怎么分；τ_seen 是「智能体在自己的世界里真正看到了锚点」，决定一次 `select` 算不算猜。两者可以不同，例如 Look→Flip 的 w1 里，第一次观察只看到「A 旁边没有 X」：此时 τ 已到，但 τ_seen 未到。

## 2. 主要指标
- **SR**：`select` 选中正确目标，且执行 `select` 时所在视点到目标的距离 ≤ 1.5m、目标在当前画面中可见（以实例掩码像素判定）
- **Obs-cost**：每回合观察类动作数（移动、转向各计 1；本任务族没有容器）
- **成功率–观察成本曲线**：对每个方法，在不同观察代价 λ（或不同解码温度阈值）下得到的 (Obs-cost, SR) 点；报告曲线下面积与给定预算点的 SR
- **Premature-commit**（2026-11-08 人类确认修订）：在 Look 类世界对的回合中，在本世界还没看到锚点就执行 `select` 的比例：`select` 的步号 < τ_seen，或回合中从未看到锚点。步号 ≥ τ_seen 的 `select` 不算过早。原定义按「区分性证据进入输入」（τ）计算；修订原因：Look→Flip 的 w1 里，智能体只看到「A 旁边没有 X」时 τ 已到，但它并没有看到 X，此时 `select` 仍然是猜，按 τ 计算会把这类猜测漏掉
- **Post-evidence update accuracy**：`select` 步号 ≥ τ_seen 的 Look 类回合中，正确改变（Look→Flip）与正确保持（Look→Stay）的比例，**两者分开报告**；同时报告进入这一统计的回合数
- **Direct Flip / Direct Stay accuracy**：t 时刻证据已足够的世界对上的目标选择正确率
- **Calibration**（2026-11-08 修订，在任何训练结果出现之前）：用训练变化频率 ρ ∈ {0.25, 0.5, 0.75} 分别训练的模型，在同一冻结测试集上的平均观察次数，以及 Look 类世界对中「先观察再 select」的比例，应随 ρ 上升。测试变化频率三档 {0, 0.25, 0.5} 下的 SR 与 Premature-commit 作为稳健性结果报告。
  修订原因：Look 类世界对在证据进入输入之前两个世界的输入逐像素相同，智能体无法感知测试时的变化频率，原定义（测试频率越高观察越多）对固定策略不成立。

## 3. 主要终点（G1 时确定，不得事后更换）
- 在 50% 与 25% 变化频率的冻结测试世界对上：相同观察预算下的 SR 与 Premature-commit
- 约束：0% 变化频率（原任务）上 SR 不显著下降

### 3b. 次要终点（2026-11-08 预注册，在任何训练结果出现之前；不替代主要终点，论文必须同时如实报告主要终点）
- **S1 证据前信用估计量的方差**（2026-11-08 人类确认修订）：每个训练步，按「独立决策单元」计算：单世界臂（T0、T2）一个回合是一个单元；配对臂（T1、T3、T4）一个世界对是一个单元。每个单元的信用 c_u = 该单元所有证据前的步（t < τ，定义见 §1b）上分到的优势之和，配对臂再除以 2（折算成每回合），优势按 T05 的损失权重计。S1 = c_u 的经验方差 ÷ 单元数（即批均值估计量的方差），在整个训练过程上取平均，按种子汇总（均值 / 标准差 / 95% CI）。主比较为 T3 对 T2；T4 一并报告。另外对 T3 的配对数据离线分解出「世界间」方差分量并报告。修订原因：原定义直接比较每一步优势值的方差，T3 的优势是两个世界的平均，按构造就更小，配对臂每步的独立决策数又只有一半，比较不公平。
- **S2 学习效率**：训练中每 20 步在训练场景留出子集上评测的成功率曲线，取曲线下面积再除以总步数，按种子汇总。比较 T4、T3 与 T0、T1、T2。留出子集在训练开始前固定，不使用冻结测试集。
