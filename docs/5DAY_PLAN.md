## 每天的固定节奏
- 早：lead 读 STATUS.md + 最新 reviews，派当天任务（每个 ≤ 2 小时、带完成标准）
- 每 4 小时：`/checkpoint`（防跑偏）
- 晚：auditor 跑一次审计；lead 更新 Gate log；人类花 20 分钟读 STATUS.md 和 Decisions

## 时间不够时的砍法（按顺序）
1. 砍第 3 条贡献，聚焦 2 条做扎实
2. 砍次要数据集，保留最有说服力的一个 + 一个泛化验证
3. 减少消融项，但保留支撑每条贡献的那一个
4. 绝不砍：baseline 公平性、seed 说明、局限性小节、引用校验
