\section*{LLM Usage Statement}
We used LLM-based assistants in this work. Claude Code (Anthropic) was used to
write and debug experiment code, to draft and edit the text of all sections, and
to search for related work. Codex (OpenAI) was used as an additional automated
reviewer of drafts. All experimental numbers in this paper are generated
programmatically from logged experiment outputs; every reference was checked
against bibliographic databases (arXiv, DBLP, Semantic Scholar, Crossref) and by
the authors. The authors designed the study, verified all results and claims, and
take full responsibility for the content of this paper.
