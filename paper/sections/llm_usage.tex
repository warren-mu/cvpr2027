\section*{LLM Usage Statement}
We used LLM-based assistants in this work. Claude (Anthropic) was used to plan
experiments, write task specifications, review experiment code, logs and results,
and draft and edit the text of all sections. Codex (OpenAI) was used to write and
debug experiment code, run experiments on the compute cluster, and retrieve
bibliographic metadata. All experimental numbers in this paper are generated
programmatically from logged experiment outputs, and every reference was checked
against bibliographic databases (arXiv, DBLP, Semantic Scholar, Crossref). The
authors designed the study, verified all results and claims, and take full
responsibility for the content of this paper.
